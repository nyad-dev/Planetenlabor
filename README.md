## Installation unter Windows (64 Bit)

1. Öffne `Planetenlabor.exe` in diesem Repository und klicke auf **Download raw file**.
2. Speichere die Datei in einem beliebigen Ordner.
3. Starte sie per Doppelklick.

Eine Installation oder eine separate Python-Umgebung ist nicht erforderlich. Die Anwendung funktioniert ohne Internetverbindung. Der erste Start kann einige Sekunden dauern.
